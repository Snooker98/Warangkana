# Warangkana Portfolio - GitHub Pages

This folder is a complete static portfolio site. It does not require Node.js or a build step.

## Publish on GitHub Pages

1. Create or open a GitHub repository for the portfolio.
2. Upload the contents of this folder to the repository root. `index.html` must be at the root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site uses relative asset paths, so it works both at `username.github.io` and in a project repository such as `username.github.io/warangkana-portfolio/`.

## Privacy

The public site intentionally excludes the phone number, street address, and downloadable resume files that contain full contact details. The contact section uses a professional email link instead.
